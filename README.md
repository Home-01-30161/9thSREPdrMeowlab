# HOMY SHOP AI CTF (Next.js)

A Thai e-commerce prompt injection CTF game with 4 escalating levels built with Next.js and Tailwind CSS.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. (Optional) Set your API key in `.env.local` if using OpenClaw / AI features:
   ```env
   NEXT_PUBLIC_OPENCLAW_API_KEY=your_key_here
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   npm start
   ```
